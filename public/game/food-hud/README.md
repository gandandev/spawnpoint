# Food HUD artwork

`appleskin-icons.png` is the unmodified `assets/appleskin/textures/icons.png`
from the supplied AppleSkin 3.0.10+mc26.2 Fabric JAR, by squeek502 and contributors.
Its Unlicense text is included in `LICENSE-AppleSkin.txt`.
Source: https://github.com/squeek502/AppleSkin/tree/26.2-fabric

`food_full.png`, `food_half.png`, `heart_full.png` and `heart_half.png` are
unmodified Minecraft hunger and heart sprites from
the hash-pinned 26.2 `assets.epk` already used by Spawnpoint. Original Minecraft
artwork belongs to Mojang Studios. These are separate from AppleSkin's license.

The browser implementation uses AppleSkin's saturation quarter-icon layout and
food recovery caps. It does not load Fabric or claim full AppleSkin compatibility.
